# Network-Engineering-Labs

This portfolio contains a collection of advanced networking labs built using Cisco Packet Tracer to demonstrate practical network engineering skills. The projects simulate real-world enterprise network environments and cover core infrastructure concepts such as enterprise Layer 2 switching, VLAN segmentation, trunking, EtherChannel, Spanning Tree optimization, gateway redundancy using HSRP, multi-area OSPF routing, enterprise edge connectivity with BGP and NAT, and network security through ACLs and port security. Each lab focuses on designing, configuring, and verifying key components of modern network architecture, with detailed configurations, topology diagrams, and explanations to illustrate how enterprise networks are built and maintained.

The purpose of this portfolio is to strengthen hands-on networking knowledge while preparing for a network engineer role. These labs focus on developing practical engineering skills such as network design, redundancy planning, routing protocol implementation, and security segmentation. By completing these projects, the goal is to bridge the gap between theoretical knowledge (such as CCNA-level concepts) and real-world network implementation, demonstrating the ability to design, configure, and troubleshoot enterprise-grade network environments.
